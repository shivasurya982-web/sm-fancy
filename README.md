# FancyWorld - Sparkle Platinum Luxury Platform

A high-fidelity luxury shop platform featuring universal simple English, glassy floating UI, and real-time synchronization.

## Project Structure

- `backend/`: Node.js server with Express, MongoDB, and Socket.io.
- `frontend/`: Flutter web/mobile application.
- `docs/`: Project documentation and design assets.

## Tech Stack

- **Backend**: Node.js, Express, MongoDB Atlas, Socket.io, JWT.
- **Frontend**: Flutter, Jetpack Compose-inspired glassy UI, Socket.io Client.

## Setup Instructions

### Backend
1. Navigate to `backend/`.
2. Create a `.env` file with `MONGODB_URI` and `JWT_SECRET`.
3. Run `npm install`.
4. Run `npm start` (Runs on Port 5050).

### Frontend
1. Navigate to `frontend/`.
2. Run `flutter pub get`.
3. Run `flutter run -d chrome` (or your preferred device).

## Visual Identity (Sparkle Platinum)
- **Backgrounds**: Deep Charcoal (#111111)
- **Accents**: Brushed Platinum
- **UI Geometry**: Capsule-based (Radius 100) and Organic containers (Radius 24-40).
